## 一、用户画像

仍是 **假设**，不是访谈结论。与 PRD 一致：交付对象是成人学习者。

### 画像 1：成人学员（主用户）——林薇（化名）

- 假设：约 28 岁，业余约 1 年，每周 1–2 次课。  
- 痛点：老师口头点评下课就忘；打字累；通用 AI 会编建议。  
- 2.0 对她已提供：语音/手打 → 结构化档案 → 反复问题与课前三句提醒。  
- 未验证：疲惫时是否仍愿意录；Progress 是否构成留存理由。

### 画像 2：青少年家长——陈女士（化名）

- **非本版用户。** 不做家长看板、不做给家长的「孩子好不好」评分（与「AI 不评价水平」冲突）。  
- 访谈时可问是否存在需求，不作为 2.0 范围。

### 画像 3：教师——苏老师（化名）

- **非本版用户。** 无老师端、无寄语。避免「被 AI 点评老师」。  
- 若做老师寄语：原话入库、不经抽取（优先级总表 P2）。

### 访谈该问的（相对 1.0 更新）

1. 课后 1–3 分钟录音是不是负担？  
2. 三段结构要不要改？常改哪一栏？  
3. 反复问题匹配会不会归错？课前卡有没有人看？  
4. 为什么用它而不是备忘录 / 通用 Chat？  
5. 家长、老师是否真要进产品——默认答案仍是「先不做」。

## 二、竞品（简版，2.0 补一列）

| 方式 | 优势 | 与 BalletMind |
| --- | --- | --- |
| 备忘录 / 手账 | 零成本 | 无抽取、无反复问题、无课前卡 |
| Keep 等健身记录 | 统计强 | 无芭蕾口述结构；我们不做运动打分 |
| 教室微信群 | 已有习惯 | 不沉淀个人档案 |
| 讯飞等转写 | 转写强 | 停在文本；无人审结构化；无追踪 |
| 通用 ChatGPT | 什么都能聊 | 易幻觉、无强制 schema、无档案、无规则追踪 |
| Grow 等习惯/运动 App | 完成感、提醒 | 非正式反馈觉得「我们更简单」；差异化应靠 **忠实抽取 + 人审 + 不让模型宣布进步**，不是靠更多功能。是否够，要等正式测试再问 |

**差异化一句话**：垂直课后口述 → 可确认的档案 → 规则追踪反复问题。价值不在「更聪明的教练」。

## 四、Case Study（面试一页，2.0）

### 背景

成人课后反馈易丢、记录散、长期问题看不见。通用工具要么太重，要么会编。

### 做了什么

从 Brief/PRD/Prompt 做到上线：语音 → Whisper → Claude 结构化 → 人确认 → Turso 档案；V0.2 用规则做反复问题、课前卡、窗口汇总。补了账号与配额。用 35 条 Eval 选了 Sonnet 5。三层指标可讲、可跑。

### 关键决策

1. **语音优先、手打兜底** — 课后不想打字；ASR 挂了产品还能活。  
2. **Human-in-the-loop** — Draft 不入库。  
3. **单次用模型，跨次不用** — 防「进步叙事」幻觉。  
4. **不 Agent / 不 RAG / 不微调** — 工作流确定；无标注教练数据；无外部知识库检索需求。  
5. **Edit Rate ≠ 错误率** — 指标诚实。  
6. **同质量换更快更便宜** — Sonnet 5 vs 4.6：35/35，延迟和费用更好；Haiku 因含糊术语硬套而落选。  
7. **Progress 从 Must Have 缺口补上** — 1.0 写了没做；2.0 用规则落地，而不是 1.0 里的 AI 周报。

### 权衡与问题

- 术语：词汇表 + 纠错记忆 + 「对不上不硬套」；ASR 仍会错，Eval 测的是错了以后模型乖不乖。  
- 60×3 未被真人样本验证。  
- 亲友说 V1 太简单 → 做了追踪；**不能**对外声称已完成用户测试。  
- 提醒仍被动（打开才看见）。  
- 漏斗旧数据不回填。

### 下一步（按价值）

1. 3–6 人结构化试用  
2. 部署带 sessionId 的埋点后读 Layer 3  
3. 确认 Render 的 `AI_MODEL`  
4. P2 与提醒往后放  

完整叙述：`docs/Case_Study_BalletMind.md`。
