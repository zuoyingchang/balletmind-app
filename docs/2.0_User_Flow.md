## 图 1 · 总览（面试/文档首页用这张）

```mermaid
flowchart TD
  A[登录 / 注册] --> B[Home 首页]
  B --> C[开始训练复盘]
  C --> D{能否录音?}
  D -->|能| E[录 1–3 段 · 每段 ≤60s]
  D -->|不能 / 不想说| F[转写框手打]
  E --> G[Whisper ASR]
  G --> H{转写成功?}
  H -->|是| I[转写可编辑]
  H -->|否| J[保留已有内容]
  J --> K{重录 / 手打 / 放弃}
  K -->|重录| E
  K -->|手打| F
  F --> I
  I --> L{日配额还够?}
  L -->|不够| M[提示配额用尽 · 禁用生成]
  L -->|够| N[Generate]
  N --> O[Claude 抽取<br/>Prompt 1.5 · tool schema]
  O --> P{结构化成功?}
  P -->|否| Q[不展示假结果]
  Q --> R{Retry / 手填保存 / 返回改转写}
  R -->|Retry| N
  R -->|改转写| I
  P -->|是| S[Review · 改 / 删 / 补]
  S --> T{用户 Confirm?}
  T -->|否| U[Draft 不入库]
  T -->|是| V[Confirm and Save]
  V --> W[训练档案]
  W --> X[规则匹配反复问题<br/>0 次 LLM]
  W --> Y[History 可搜可删]
  W --> Z[Progress 可选]
  Z --> Z1[课前卡最多 3 句]
  Z --> Z2[最近 7 天 / 最近 5 次汇总]
  Z --> Z3[问题状态：有改善 / 仍在 / 已解决]
```

## 图 2 · Capture 漏斗（和 Layer 3 session 对齐）

同一 `sessionId` 才算一次语音转化。手打进档案 **不算进这条语音漏斗**。

```mermaid
flowchart LR
  S1[record_started<br/>开始录音] --> S2[voice_completed<br/>录完出字]
  S2 --> S3[asr_success]
  S3 --> S4[ai_process_success]
  S4 --> S5[review_opened]
  S5 --> S6[session_confirmed<br/>确认保存]

  S3x[asr_fail] -.-> S3
  S4x[ai_process_fail] -.-> S4
  S5e[field_edited<br/>只记字段名] -.-> S5
  S5r[ai_regenerated<br/>Retry] -.-> S4
```

侧指标（不是漏斗台阶）：History / Progress 用 browse session，不挂在这一次课上。

## 图 3 · 异常与降级（宁可少生成，也不编造）

```mermaid
flowchart TD
  IN[已有录音或转写] --> A{哪一步坏了?}

  A -->|麦克风 / 浏览器| B[手打转写 · 不卡死]
  A -->|ASR 失败 / 超时| C[不调用假整理]
  C --> D[重录 或 手打]
  A -->|AI 失败 / 超时 / 无 tool| E[不展示假 Success]
  E --> F[保留转写]
  F --> G[Retry 或 手填后保存]
  A -->|配额用尽| H[入口说明 · 禁用 Generate]
  A -->|信息不足| I[空字段合法<br/>note：用户描述信息有限]
  A -->|注入 / 与课无关| J[低置信 · note 说明 · 不执行指令]

  B --> K[仍可进入 Generate]
  D --> K
  G --> L{Confirm?}
  K --> L
  H --> M[本次无法走 AI]
  I --> L
  J --> L
  L -->|是| N[入库]
  L -->|否| O[不进长期档案]
```

## 图 4 · 保存之后：档案 + Progress（规则，不打断主路径）

```mermaid
flowchart TD
  SAVE[用户 Confirm 保存] --> REC[Turso 一条 Confirmed Record]
  REC --> HIST[History<br/>日期 / 课名 / 搜索]
  REC --> MATCH[文本归一化匹配<br/>improve_points]

  MATCH --> NEW{对得上已有未解决条目?}
  NEW -->|是| BUMP[出现次数 +1 · 记下课次]
  NEW -->|否| OPEN[新建反复问题]

  BUMP --> LIST[追踪列表]
  OPEN --> LIST
  LIST --> ST[用户点状态]
  ST --> ST1[有改善]
  ST --> ST2[仍然存在]
  ST --> ST3[已解决 · 离开列表]

  LIST --> EVI[证据：次数 + 日期 · 回链记录]
  LIST --> BRIEF[课前看一眼<br/>最多 3 条短句 · 0 次 LLM]
  HIST --> WIN[最近 7 天 或 最近 5 次<br/>规则汇总 · 0 次 LLM]

  WIN --> EMPTY{样本不够?}
  EMPTY -->|是| ES[空态 · 不编规律]
  EMPTY -->|否| SUM[次数 / 反复问题 / 用户写过的进步原话]

  NOTE[禁止：模型宣布进步、打分、百分比提升]
```
