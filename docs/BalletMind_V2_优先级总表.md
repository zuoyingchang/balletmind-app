# BalletMind V0.2（Progress Intelligence）｜功能优先级总表

> 定位：从 V0.1 的 Capture & Structure（记录），升级为 Track → Understand → Act（追踪→理解→行动）  
> 核心原则：主流程不变复杂，所有新增都是用户主动触发的可选分支  
> 对照代码：2026-09-19（含问问你的档案；课前卡多 Agent Experiment 默认关）  
> 编号仍用原表 #1–#18 与遗留 A/B，方便和旧文档对上

## 一句话面试复述版

> V0.2 要从「记下一次课」变成「看见自己反复出现的问题、课前能看一眼、按周或按最近五次能汇总一下」。这三块已经用规则 + 用户自己改状态做上了。追踪页还可以问问档案：RAG 找出相关课记，Agent 据此回答。还没做的是问题图表、老师寄语对照。原则没变：AI 整理原话或引用已保存内容，不在成长结论上替用户说话。
