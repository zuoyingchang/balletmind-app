## 图 1 · 总览（面试/文档首页用这张）

```mermaid
flowchart TD
  A[登录 / 注册] --> B[首页]
  B --> C[复盘今天 / 再记一笔]
  C --> D{能否录音?}
  D -->|能| E[录 1–3 段 · 每段 ≤60s]
  D -->|不能 / 不想说| F[转写框手打]
  E --> G[Whisper ASR]
  G --> H{转写成功?}
  H -->|是| I[转写可编辑]
  H -->|否| J[保留已有内容]
  J --> K{重录 / 手打 / 放弃}
  K -->|重录| E
  K -->|手打| F
  F --> I
  I --> L{日配额还够?}
  L -->|不够| M[提示配额用尽 · 禁用生成]
  L -->|够| N[完成并生成 · 吸底]
  N --> N1[正在整理你说过的话]
  N1 --> O[Claude 抽取<br/>Prompt 1.7 · tool schema]
  O --> P{结构化成功?}
  P -->|否| Q[不展示假结果]
  Q --> R{Retry / 手填保存 / 返回改转写}
  R -->|Retry| N
  R -->|改转写| I
  P -->|是| S[草稿默认三段 + 确认保存]
  S --> S1[还可以记下：课名/时长/心情/小提示/转写]
  S1 --> T{用户 Confirm?}
  T -->|否| U[Draft 不入库]
  T -->|是| V[Confirm and Save]
  V --> W[训练档案]
  W --> X[规则匹配反复问题]
  W --> Y[History 可搜 · 术语标签可点]
  W --> Z[追踪可选]
  Z --> Z1[先看反复问题]
  Z --> Z2[课前看一眼 · 规则卡]
  Z --> Z3[问问你的档案]
  Z --> Z4[最近状态可展开：14天 / 7天或5次]
```

## 图 2 · Capture 漏斗（和 Layer 3 session 对齐）

同一 `sessionId` 才算一次语音转化。手打进档案 **不算进这条语音漏斗**。

```mermaid
flowchart LR
  S1[record_started<br/>开始录音] --> S2[voice_completed<br/>录完出字]
  S2 --> S3[asr_success]
  S3 --> S4[ai_process_success]
  S4 --> S5[review_opened]
  S5 --> S6[session_confirmed<br/>确认保存]

  S3x[asr_fail] -.-> S3
  S4x[ai_process_fail] -.-> S4
  S5e[field_edited<br/>只记字段名] -.-> S5
  S5r[ai_regenerated<br/>Retry] -.-> S4
```

侧指标（不是漏斗台阶）：History / Progress / 问问档案用 browse session，不挂在这一次课上。

## 图 3 · 异常与降级（宁可少生成，也不编造）

```mermaid
flowchart TD
  IN[已有录音或转写] --> A{哪一步坏了?}

  A -->|麦克风 / 浏览器| B[手打转写 · 不卡死]
  A -->|ASR 失败 / 超时| C[不调用假整理]
  C --> D[重录 或 手打]
  A -->|AI 失败 / 超时 / 无 tool| E[不展示假 Success]
  E --> F[保留转写]
  F --> G[Retry 或 手填后保存]
  A -->|配额用尽| H[入口说明 · 禁用生成]
  A -->|信息不足| I[空字段合法<br/>note：用户描述信息有限]
  A -->|注入 / 与课无关| J[低置信 · note 说明 · 不执行指令]

  B --> K[仍可进入生成]
  D --> K
  G --> L{Confirm?}
  K --> L
  H --> M[本次无法走 AI]
  I --> L
  J --> L
  L -->|是| N[入库]
  L -->|否| O[不进长期档案]
```

## 图 4 · 保存之后：档案 + Progress

```mermaid
flowchart TD
  SAVE[用户 Confirm 保存] --> REC[Turso 一条 Confirmed Record]
  REC --> HIST[History<br/>日期 / 课名 / 搜索]
  REC --> MATCH[文本归一化匹配<br/>improve_points]

  MATCH --> NEW{对得上已有未解决条目?}
  NEW -->|是| BUMP[出现次数 +1 · 记下课次]
  NEW -->|否| OPEN[新建反复问题]

  BUMP --> LIST[追踪列表]
  OPEN --> LIST
  LIST --> ST[用户点状态]
  ST --> ST1[有改善]
  ST --> ST2[仍然存在]
  ST --> ST3[已解决 · 离开列表]

  LIST --> EVI[证据：次数 + 日期 · 回链记录]
  LIST --> BRIEF[课前看一眼 · 规则卡<br/>最多 3 条 · 多Agent实验默认关]
  LIST --> ASK[问问你的档案]
  HIST --> WIN[最近 7 天 或 最近 5 次<br/>规则汇总]

  WIN --> EMPTY{样本不够?}
  EMPTY -->|是| ES[空态 · 不编规律]
  EMPTY -->|否| SUM[次数 / 反复问题 / 用户写过的进步原话]

  NOTE[禁止：模型宣布进步、打分、百分比提升]
```

## 图 5 · 问问你的档案（RAG + Agent）

```mermaid
flowchart TD
  Q[用户提问] --> KW[关键词检索]
  KW --> SPARSE{命中条数 ≤ 1?}
  SPARSE -->|否，已有 ≥2 条| HIT{找到相关记录?}
  SPARSE -->|是| EMB[Embedding 补检索]
  EMB --> HIT
  HIT -->|否| NO[告诉用户没有相关记录]
  HIT -->|是| AGENT[Agent：根据这些课记作答]
  AGENT --> NEED{现有记录够不够回答?}
  NEED -->|够| ANS[submit_answer<br/>并列引用 · 不宣布进步]
  NEED -->|要对比另一个时间段| SEARCH[再检索一次<br/>同一套规则 + 日期范围]
  SEARCH --> ANS2[给出最终回答]
  ANS --> CITE[引用可点回课次]
  ANS2 --> CITE
```

## 图 6 · 技术架构总览（RAG / Agent / 多Agent 分布，含 experiments 新Feature）

生产课前卡和反复问题走规则（0 次 LLM）。问问档案是线上唯一的 RAG + 单 Agent。多 Agent 课前提醒（分析 → 写作 → 审核，审核失败打回写作，最终失败回退规则卡）已接到 `GET /api/progress/brief`，但用双开关默认全关（`EXPERIMENT_ISSUE_BRIEF` + 用户白名单，默认均空），**不对任何用户开启**。LangGraph 版问问档案仍只在 `experiments/` 做对照，不替换生产单 Agent。

```mermaid
flowchart TD
  A[语音录制 / 手打降级] --> B[Whisper ASR 转写<br/>术语库纠偏 · 规则]
  B --> C[AI 结构化<br/>单次 LLM 调用]:::llm
  C --> D[人工确认后保存]
  D --> E[History 关键词搜索<br/>规则匹配 · 无 AI]
  D --> F[反复问题 + 课前卡<br/>规则 · 0 次 LLM · 默认全员]:::rule
  D --> G[问问你的档案<br/>RAG + 单 Agent · 生产]:::agent

  subgraph EXP[Experiment / 新Feature]
    H[LangGraph 问问档案<br/>对照实现 · 不替换生产]:::agent
    I[课前卡多 Agent<br/>分析→写作→审核<br/>已接线 · 双开关默认关]:::multiagent
  end

  G -. 对照 .-> H
  F -. 闸门关闭时不走 .-> I

  classDef llm fill:#B5D4F4,stroke:#185FA5,color:#042C53
  classDef agent fill:#9FE1CB,stroke:#0F6E56,color:#04342C
  classDef multiagent fill:#CECBF6,stroke:#534AB7,color:#26215C
  classDef rule fill:#E8E8E8,stroke:#888,color:#333
```

## 怎么读这些图

| 图 | 回答什么 |
| --- | --- |
| 1 | 用户从登录到存档、以及 Progress 在哪分叉 |
| 2 | 埋点漏斗，避免 unique 用户相除 |
| 3 | ASR/AI 挂了产品怎么活 |
| 4 | 保存之后：规则追踪 + 问问档案入口 |
| 5 | RAG 先关键词，命中不够才 Embedding；Agent 据此回答 |
| 6 | 全链路哪里是规则、哪里是单次LLM、哪里是RAG+Agent、哪里是多Agent；生产 vs experiments 新Feature 的边界 |

1.0 文档里的「Generate 后 AI 写周复盘」**不要画进 2.0**。周/次汇总只走图 4 的规则框。
