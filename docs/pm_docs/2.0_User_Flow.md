> 原则：**主路径一次课走完保存**；确认页两段事实（做得好的 / 还要改的）；ASR/AI 挂了不编造成功。Progress 是保存之后的可选支路。课前卡和反复问题默认用规则。问问档案：检索后直接列出课记原文（做得好的 / 待改进 / 问档案时才有已解决），**不**再让大模型写一段新回答。多 Agent 课前卡是 Experiment，已接线、双开关默认关。账号支路：「我的」可导出全部数据或注销删账号（需密码，不画进主漏斗）。**只打卡**是首页旁路：不录音、不占 AI 复盘额度、不算语音漏斗完成。额度用尽走手动记，不卡死。

## 图 1 · 总览（面试/文档首页用这张）

```mermaid
flowchart TD
  A[登录 / 注册] --> B[首页]
  B --> C[记录今天 / 再记一节]
  C --> D{能否录音?}
  D -->|能| E[录 1–2 段 · 各约 1 分钟]
  D -->|不能 / 不想说| MAN[手动记 · 打卡式一页]
  E --> G[Whisper ASR<br/>可选腾讯云备用 · 默认关]
  G --> H{转写成功?}
  H -->|是| I[转写可编辑]
  H -->|否| J[保留已有内容]
  J --> K{重录 / 手动记 / 放弃}
  K -->|重录| E
  K -->|手动记| MAN
  I --> L{今天 AI 复盘额度还够?<br/>默认 2 次}
  L -->|不够| M[进记录页并打开手动记]
  L -->|够| N[完成并生成]
  N --> N1[正在整理你说过的话]
  N1 --> O[LLM 抽取<br/>Prompt 2.2 · tool schema]
  O --> P{结构化成功?}
  P -->|否| Q[不展示假结果]
  Q --> R{Retry / 手动记 / 返回改转写}
  R -->|Retry| N
  R -->|改转写| I
  R -->|手动记| MAN
  P -->|是| S[草稿两段 + 确认保存]
  MAN --> S2[做得好的 + 还要改的 · 必填]
  S --> S1[课程/组合芯片 · 时长心情可选]
  S1 --> T{用户 Confirm?}
  S2 --> T
  T -->|否| U[Draft 不入库]
  T -->|是| V[Confirm and Save]
  V --> W[训练档案]
  W --> X[规则匹配反复问题]
  W --> Y[History 可搜 · 统计/列表]
  W --> Z[追踪可选]
  Z --> Z1[问题：反复出现]
  Z --> Z2[课前看一眼 · 最近一则还要改的]
  Z --> Z3[回看：问AI / 术语 / 汇总]
```

## 图 2 · Capture 漏斗（和 Layer 3 session 对齐）

同一 `sessionId` 才算一次语音转化。手打 / 手动记进档案 **不算进这条语音漏斗**。

```mermaid
flowchart LR
  S1[record_started<br/>开始录音] --> S2[voice_completed<br/>录完出字]
  S2 --> S3[asr_success]
  S3 --> S4[ai_process_success]
  S4 --> S5[review_opened]
  S5 --> S6[session_confirmed<br/>确认保存]

  S3x[asr_fail] -.-> S3
  S4x[ai_process_fail] -.-> S4
  S5e[field_edited<br/>只记字段名] -.-> S5
  S5r[ai_regenerated<br/>Retry] -.-> S4
```

侧指标（不是漏斗台阶）：History / Progress / 问问档案用 browse session，不挂在这一次课上。

## 图 3 · 异常与降级（宁可少生成，也不编造）

```mermaid
flowchart TD
  IN[已有录音或转写] --> A{哪一步坏了?}

  A -->|麦克风 / 浏览器| B[手打或手动记 · 不卡死]
  A -->|ASR 失败 / 超时| C[不调用假整理]
  C --> D[重录 或 手动记]
  A -->|AI 失败 / 超时 / 无 tool| E[不展示假 Success]
  E --> F[保留转写]
  F --> G[Retry 或 手动记后保存]
  A -->|今天 AI 复盘额度用尽| H[记录页自动打开手动记]
  A -->|信息不足| I[空字段不补全<br/>两段事实必填才能保存]
  A -->|注入 / 与课无关| J[低置信 · note 说明 · 不执行指令]

  B --> K[仍可进入生成或手动记]
  D --> K
  G --> L{Confirm?}
  K --> L
  H --> M[本次不走 AI · 可自己写两段]
  I --> L
  J --> L
  L -->|是| N[入库]
  L -->|否| O[不进长期档案]
```

## 图 4 · 保存之后：档案 + Progress

```mermaid
flowchart TD
  SAVE[用户 Confirm 保存] --> REC[Turso 一条 Confirmed Record]
  REC --> HIST[档案<br/>统计 / 列表 / 搜索]
  REC --> MATCH[文本归一化匹配<br/>improve_points]

  MATCH --> NEW{对得上已有未解决条目?}
  NEW -->|是| BUMP[出现次数 +1 · 记下课次]
  NEW -->|否| OPEN[新建反复问题 · 出现 ≥1 次即列出]

  BUMP --> LIST[追踪 · 问题]
  OPEN --> LIST
  LIST --> ST[用户点状态]
  ST --> ST1[有改善]
  ST --> ST2[仍然存在]
  ST --> ST3[已解决 · 离开列表]

  LIST --> EVI[证据：次数 + 日期 · 回链记录]
  LIST --> BRIEF[课前看一眼<br/>最近一则还带还要改的课记]
  LIST --> ASK[回看 · 问AI]
  HIST --> WIN[汇总报告<br/>近 7 天 或 近 5 次 · 规则]

  WIN --> EMPTY{样本不够?}
  EMPTY -->|是| ES[空态 · 不编规律]
  EMPTY -->|否| SUM[做得好的 / 还要改的 原话]

  NOTE[禁止：模型宣布进步、打分、百分比提升]
```

## 图 5 · 问问你的档案（检索 + 原文归纳，不二次写作）

```mermaid
flowchart TD
  Q[用户提问] --> RANGE[可选：解析日期范围]
  RANGE --> KW[关键词检索已确认课记]
  KW --> SPARSE{命中条数 ≤ 1?}
  SPARSE -->|否，已有 ≥2 条| HIT{找到相关记录?}
  SPARSE -->|是| EMB[Embedding 补检索]
  EMB --> HIT
  HIT -->|否| NO[告诉用户没有相关记录]
  HIT -->|是| DIG[服务端归纳原文<br/>做得好的 / 待改进]
  DIG --> ARCH{问的是档案/已解决?}
  ARCH -->|是| RES[加一栏已解决]
  ARCH -->|否| PAGE[每栏最多先列 5 条]
  RES --> PAGE
  PAGE --> MORE[还可再加载 5 条]
  PAGE --> CITE[一行一条 · 课名+日期 · 可点回课次]
  MORE --> CITE
  DIG --> FOLD[可收起：左边是问题，右边收起]
```

生产 `/api/progress/ask` **不调用** Claude / DeepSeek 写回答。仓库里仍有 `ASK_PROMPT` 2.3 与对照脚本，只作实验，不是现网路径。

## 图 6 · 技术架构总览（含 experiments）

生产课前卡和反复问题走规则（0 次 LLM）。问问档案是线上 RAG 检索 + 服务端 digest，不再走单 Agent 写作。抽取是单次 LLM（默认 Anthropic；可配 DeepSeek 等 openai-compatible，超时约 5s 可切备用）。多 Agent 课前提醒已接到 `GET /api/progress/brief`，双开关默认全关。LangGraph 问问档案只在 `experiments/`。

```mermaid
flowchart TD
  A[语音录制 / 手动记降级] --> B[Whisper ASR 转写<br/>术语库纠偏 · 腾讯备用默认关]
  B --> C[AI 结构化<br/>单次 LLM · Prompt 2.2]:::llm
  C --> D[人工确认后保存]
  D --> E[档案搜索 / 统计<br/>规则 · 无 AI]
  D --> F[反复问题 + 课前卡<br/>规则 · 0 次 LLM]:::rule
  D --> G[问问你的档案<br/>RAG + digest · 生产]:::agent

  subgraph EXP[Experiment / 未对用户开]
    H[ASK_PROMPT / LangGraph 问问档案<br/>对照 · 不替换生产]:::agent
    I[课前卡多 Agent<br/>分析→写作→审核<br/>双开关默认关]:::multiagent
  end

  G -. 对照 .-> H
  F -. 闸门关闭时不走 .-> I

```

## 怎么读这些图

| 图 | 回答什么 |
| --- | --- |
| 1 | 用户从登录到存档、以及 Progress 在哪分叉 |
| 2 | 埋点漏斗，避免 unique 用户相除 |
| 3 | ASR/AI 挂了、额度用尽时产品怎么活 |
| 4 | 保存之后：规则追踪 + 问档案入口 |
| 5 | RAG 先关键词，命中不够才 Embedding；列出课记原文，不二次写作 |
| 6 | 全链路哪里是规则、哪里是单次LLM、哪里是检索、哪里是多Agent |

1.0 文档里的「Generate 后 AI 写周复盘」**不要画进 2.0**。周/次汇总只走图 4 的规则框。
